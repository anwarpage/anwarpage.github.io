# anwarv1

Minimalist editorial personal website for **M. Kaspul Anwar**, built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, `next-themes`, and `sugar-high`.

## Highlights

- **Original editorial layout:** Asymmetric masthead paired with a two-track margin-grid index across work, writing, principles, and background.
- **Non-cliché typography:** `Newsreader` (reading & display serif) + `Public Sans` (utilitarian UI sans) + `IBM Plex Mono` (tabular dates, indices, and code).
- **Animated Dino illustration:** Interactive SVG gouache-and-grain plate featuring Anwar's blue T-Rex mascot studying by a calm Banjarmasin river meadow, with CSS `@property --breeze` hover/click wind motion, automatic daylight/starry-night theme shift, and a quiet pause/play control.
- **Static Markdown case studies:** All 10 project case studies rendered statically with lightweight `sugar-high` syntax highlighting.

## Run Locally

```bash
npm install
npm run dev
```
